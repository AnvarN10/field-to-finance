# F2F Solana Program Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and test the `f2f` Anchor program that carries a Pool from field registration to investor redemption, plus the Nx workspace around it.

**Architecture:** One Anchor 1.2 program with one file per instruction. Pool money is USDC (classic SPL Token in tests, devnet USDC later); the Instrument is a Token-2022 mint per Pool with frozen-by-default accounts and on-mint metadata, created by manual CPIs because Anchor has no `default_account_state` constraint. Tests are Rust integration tests on LiteSVM.

**Tech Stack:** Anchor CLI and `anchor-lang`/`anchor-spl` 1.2.0, Solana CLI 3.1.11 (platform tools v1.57, sbpf v3), Rust 1.97.1 for host tests, litesvm 0.17.0, Nx 23 with pnpm.

**Spec:** [docs/specs/2026-10-03-mvp-design.md](../specs/2026-10-03-mvp-design.md)

## Global Constraints

- Deadline 2026-10-12 23:59 PT; commit small, push daily, never squash or rewrite pushed history.
- Anchor `1.2.0` exactly; `CpiContext::new` takes a program id `Pubkey`, not an `AccountInfo`.
- Host toolchain `1.97.1` in `anchor/rust-toolchain.toml` (litesvm 0.17 pulls agave crates that need it). The program itself is built by `cargo-build-sbf` with its own toolchain.
- Test crates: `litesvm = "0.17.0"`, `solana-message = "4.6.0"`, `solana-transaction = { version = "4.3.0", features = ["verify"] }`, `solana-signer = "3.0.0"`, `solana-keypair = "3.0.1"`, `spl-associated-token-account-interface = "2.0.0"`. litesvm 0.10 from the Anchor template cannot load sbpf v3 programs.
- Instrument: Token-2022, 6 decimals, 1 unit = 1 USDC face value, Default Account State = Frozen, Metadata Pointer to the mint itself, mint and freeze authority = Pool PDA.
- Tokenized Share = 30% of expected harvest (`TOKENIZED_SHARE_BPS = 3_000`).
- Premium must be 500–600 bps inclusive.
- Fixed yield is paid in USDC regardless of grain price and regardless of Shortfall rule.
- Amounts are integer USDC base units (6 decimals). Harvest volumes are integer kilograms.
- No personal data on-chain.
- Docs in English; update `docs/` in the same commit as behavior changes.

## Review Focus

- **Duplicate roles in one wallet.** If admin configures the same key as issuer and compliance, every instruction must still work; role checks compare keys, they do not assume distinct wallets. Test: `init_config` with issuer = compliance, then `approve_investor` and `create_pool` succeed (Task 1 harness reuses keys in one test).
- **Arithmetic overflow on large pools.** `raised * (10_000 + yield_bps)` must use checked u128 math; a 10 billion USDC pool must not wrap. Test in Task 7.
- **Second `record_attestation(FieldVerified, Pass)` on an already verified field** must not increment `verified_field_count` twice. Test in Task 3.
- **Subscribing exactly up to target** must succeed and allow `close_subscription` before the close time. Test in Task 5.
- **Redeeming partial amounts** across several calls must pay the same rate each time and never exceed the vault. Test in Task 7.

use anchor_lang::{
    prelude::Pubkey,
    solana_program::{instruction::Instruction, program_pack::Pack, system_instruction, system_program},
    AccountDeserialize, InstructionData, ToAccountMetas,
};
use anchor_spl::token::spl_token;

use litesvm::LiteSVM;
use solana_keypair::Keypair;
use solana_message::{Message, VersionedMessage};
use solana_signer::Signer;
use solana_transaction::versioned::VersionedTransaction;
use spl_associated_token_account_interface::{
    address::get_associated_token_address_with_program_id, instruction::create_associated_token_account_idempotent,
};

pub const USDC: u64 = 1_000_000;

pub struct Env {
    pub svm: LiteSVM,
    pub admin: Keypair,
    pub issuer: Keypair,
    pub scas: Keypair,
    pub compliance: Keypair,
    pub producer: Keypair,
    pub investor: Keypair,
    pub usdc_mint: Keypair,
}

impl Env {
    /// Method form so callers can build instructions from `&env` inside the argument list
    /// (two-phase borrows apply to method receivers, not to `&mut env.svm` arguments).
    pub fn send(&mut self, ixs: &[Instruction], payer: &Keypair, extra: &[&Keypair]) -> Result<(), String> {
        send(&mut self.svm, ixs, payer, extra)
    }

    pub fn send_err(&mut self, ixs: &[Instruction], payer: &Keypair, extra: &[&Keypair]) -> String {
        send_err(&mut self.svm, ixs, payer, extra)
    }
}

pub fn program_id() -> Pubkey {
    f2f::id()
}

pub fn send(svm: &mut LiteSVM, ixs: &[Instruction], payer: &Keypair, extra: &[&Keypair]) -> Result<(), String> {
    let mut signers: Vec<&Keypair> = vec![payer];
    signers.extend_from_slice(extra);
    svm.expire_blockhash();
    let msg = Message::new_with_blockhash(ixs, Some(&payer.pubkey()), &svm.latest_blockhash());
    let tx = VersionedTransaction::try_new(VersionedMessage::Legacy(msg), &signers).unwrap();
    svm.send_transaction(tx).map(|_| ()).map_err(|e| format!("{:?}\n{}", e.err, e.meta.logs.join("\n")))
}

/// Sends and asserts failure; returns the logs so tests can match the error name.
pub fn send_err(svm: &mut LiteSVM, ixs: &[Instruction], payer: &Keypair, extra: &[&Keypair]) -> String {
    match send(svm, ixs, payer, extra) {
        Ok(()) => panic!("transaction was expected to fail"),
        Err(e) => e,
    }
}

pub fn ix<D: InstructionData, A: ToAccountMetas>(data: D, accounts: A) -> Instruction {
    Instruction::new_with_bytes(program_id(), &data.data(), accounts.to_account_metas(None))
}

pub fn fetch<T: AccountDeserialize>(svm: &LiteSVM, key: &Pubkey) -> T {
    let acc = svm.get_account(key).expect("account missing");
    T::try_deserialize(&mut acc.data.as_slice()).unwrap()
}

pub fn token_balance(svm: &LiteSVM, account: &Pubkey) -> u64 {
    let acc = svm.get_account(account).expect("token account missing");
    // Amount sits at the same offset (64..72) for SPL Token and Token-2022 accounts.
    u64::from_le_bytes(acc.data[64..72].try_into().unwrap())
}

/// Creates a classic SPL Token mint with 6 decimals acting as USDC.
pub fn create_usdc_mint(svm: &mut LiteSVM, payer: &Keypair, mint: &Keypair) {
    let rent = svm.minimum_balance_for_rent_exemption(spl_token::state::Mint::LEN);
    let create = system_instruction::create_account(&payer.pubkey(), &mint.pubkey(), rent, spl_token::state::Mint::LEN as u64, &spl_token::ID);
    let init = spl_token::instruction::initialize_mint2(&spl_token::ID, &mint.pubkey(), &payer.pubkey(), None, 6).unwrap();
    send(svm, &[create, init], payer, &[mint]).unwrap();
}

/// Creates the owner's USDC ATA if needed and mints `amount` to it. `env.admin` is the USDC mint authority.
pub fn fund_usdc(env: &mut Env, owner: &Pubkey, amount: u64) -> Pubkey {
    let account = ata(owner, &env.usdc_mint.pubkey(), &spl_token::ID);
    let create = create_associated_token_account_idempotent(&env.admin.pubkey(), owner, &env.usdc_mint.pubkey(), &spl_token::ID);
    let mint_to = spl_token::instruction::mint_to(&spl_token::ID, &env.usdc_mint.pubkey(), &account, &env.admin.pubkey(), &[], amount).unwrap();
    let admin = env.admin.insecure_clone();
    env.send(&[create, mint_to], &admin, &[]).unwrap();
    account
}

pub fn now(svm: &LiteSVM) -> i64 {
    svm.get_sysvar::<anchor_lang::prelude::Clock>().unix_timestamp
}

pub fn warp_to(svm: &mut LiteSVM, unix_timestamp: i64) {
    let mut clock = svm.get_sysvar::<anchor_lang::prelude::Clock>();
    clock.unix_timestamp = unix_timestamp;
    svm.set_sysvar(&clock);
}

pub fn setup() -> Env {
    let mut svm = LiteSVM::new();
    svm.add_program(program_id(), include_bytes!(concat!(env!("CARGO_TARGET_TMPDIR"), "/../deploy/f2f.so"))).unwrap();

use crate::{
    constants::*,
    error::F2fError,
    state::{Attestation, AttestationKind, Config, FarmProject, Field, Verdict},
};

#[derive(Accounts)]
pub struct RecordAttestation<'info> {
    #[account(mut, address = config.scas @ F2fError::Unauthorized)]
    pub scas: Signer<'info>,
    #[account(seeds = [CONFIG_SEED], bump = config.bump)]
    pub config: Account<'info, Config>,
    #[account(mut)]
    pub project: Account<'info, FarmProject>,
    #[account(mut, constraint = field.project == project.key() @ F2fError::FieldMismatch)]
    pub field: Account<'info, Field>,
    #[account(
        init,
        payer = scas,
        space = 8 + Attestation::INIT_SPACE,
        seeds = [ATTESTATION_SEED, field.key().as_ref(), &field.attestation_count.to_le_bytes()],
        bump
    )]
    pub attestation: Account<'info, Attestation>,
    pub system_program: Program<'info, System>,
}

pub fn handle_record_attestation(
    ctx: Context<RecordAttestation>,
    kind: AttestationKind,
    verdict: Verdict,
    evidence_hash: [u8; 32],
    evidence_uri: String,
    ndvi_mean_x10k: i16,
    scene_date: i64,
) -> Result<()> {
    require!(evidence_uri.len() <= MAX_URI_LEN, F2fError::StringTooLong);
    require!((-NDVI_SCALE..=NDVI_SCALE).contains(&ndvi_mean_x10k), F2fError::InvalidNdvi);
    let field = &mut ctx.accounts.field;
    let project = &mut ctx.accounts.project;

    let a = &mut ctx.accounts.attestation;
    a.field = field.key();
    a.project = project.key();
    a.sequence = field.attestation_count;
    a.kind = kind;
    a.verdict = verdict;
    a.evidence_hash = evidence_hash;
    a.evidence_uri = evidence_uri;
    a.ndvi_mean_x10k = ndvi_mean_x10k;
    a.scene_date = scene_date;
    a.signer = ctx.accounts.scas.key();
    a.recorded_at = Clock::get()?.unix_timestamp;
    a.bump = ctx.bumps.attestation;

    field.attestation_count += 1;
    if kind == AttestationKind::FieldVerified && verdict == Verdict::Pass && !field.verified {
        field.verified = true;
        project.verified_field_count += 1;
    }
    if kind == AttestationKind::Harvest {
        project.harvest_attested = true;
    }
    Ok(())
}

pub fn handle_create_pool(ctx: Context<CreatePool>, pool_id: u64, args: CreatePoolArgs) -> Result<()> {
    require!(args.crop.len() <= MAX_CROP_LEN, F2fError::StringTooLong);
    require!(args.name.len() <= MAX_NAME_LEN, F2fError::StringTooLong);
    require!(args.symbol.len() <= MAX_SYMBOL_LEN, F2fError::StringTooLong);
    require!(args.uri.len() <= MAX_URI_LEN, F2fError::StringTooLong);
    require!((PREMIUM_MIN_BPS..=PREMIUM_MAX_BPS).contains(&args.premium_bps), F2fError::InvalidPremium);
    require!(args.yield_bps <= MAX_YIELD_BPS, F2fError::InvalidYield);
    let now = Clock::get()?.unix_timestamp;
    require!(now < args.subscription_close_ts && args.subscription_close_ts < args.maturity_ts, F2fError::InvalidSchedule);

    let pool_key = ctx.accounts.pool.key();
    let mint_key = ctx.accounts.mint.key();
    let pool_bump = ctx.bumps.pool;
    let mint_bump = ctx.bumps.mint;
    let pool_id_bytes = pool_id.to_le_bytes();
    let pool_seeds: &[&[u8]] = &[POOL_SEED, &pool_id_bytes, &[pool_bump]];
    let mint_seeds: &[&[u8]] = &[MINT_SEED, pool_key.as_ref(), &[mint_bump]];
    let token_program_id = ctx.accounts.token_program.key();

    // Anchor has no default_account_state constraint, so the mint is built by hand:
    // allocate with room for the fixed extensions, fund rent for the metadata that
    // token_metadata_initialize appends, then initialize extensions before the mint.
    let space = ExtensionType::try_calculate_account_len::<MintState>(&[
        ExtensionType::DefaultAccountState,
        ExtensionType::MetadataPointer,
    ])?;
    let metadata = TokenMetadata {
        mint: mint_key,
        name: args.name.clone(),
        symbol: args.symbol.clone(),
        uri: args.uri.clone(),
        ..Default::default()
    };
    let lamports = Rent::get()?.minimum_balance(space + metadata.tlv_size_of()?);
    create_account(
        CpiContext::new_with_signer(
            anchor_lang::system_program::ID,
            CreateAccount { from: ctx.accounts.issuer.to_account_info(), to: ctx.accounts.mint.to_account_info() },
            &[mint_seeds],
        ),
        lamports,
        space as u64,
        &token_program_id,
    )?;
    default_account_state_initialize(
        CpiContext::new(
            token_program_id,
            DefaultAccountStateInitialize {
                token_program_id: ctx.accounts.token_program.to_account_info(),
                mint: ctx.accounts.mint.to_account_info(),
            },
        ),
        &AccountState::Frozen,
    )?;
    metadata_pointer_initialize(
        CpiContext::new(
            token_program_id,
            MetadataPointerInitialize {
                token_program_id: ctx.accounts.token_program.to_account_info(),
                mint: ctx.accounts.mint.to_account_info(),
            },
        ),
        Some(pool_key),
        Some(mint_key),
    )?;
    initialize_mint2(
        CpiContext::new(token_program_id, InitializeMint2 { mint: ctx.accounts.mint.to_account_info() }),
        INSTRUMENT_DECIMALS,
        &pool_key,
        Some(&pool_key),
    )?;
    token_metadata_initialize(
        CpiContext::new_with_signer(
            token_program_id,
            TokenMetadataInitialize {
                program_id: ctx.accounts.token_program.to_account_info(),
                metadata: ctx.accounts.mint.to_account_info(),
                update_authority: ctx.accounts.pool.to_account_info(),
                mint_authority: ctx.accounts.pool.to_account_info(),
                mint: ctx.accounts.mint.to_account_info(),
            },
            &[pool_seeds],
        ),
        args.name,
        args.symbol,
        args.uri,
    )?;

    let pool = &mut ctx.accounts.pool;
    pool.pool_id = pool_id;
    pool.issuer = ctx.accounts.issuer.key();
    pool.mint = mint_key;
    pool.vault = ctx.accounts.vault.key();
    pool.crop = args.crop;
    pool.season = args.season;
    pool.target_amount = 0;
    pool.raised_amount = 0;
    pool.yield_bps = args.yield_bps;
    pool.premium_bps = args.premium_bps;
    pool.subscription_close_ts = args.subscription_close_ts;
    pool.maturity_ts = args.maturity_ts;
    pool.project_count = 0;
    pool.disbursed_count = 0;
    pool.settled_count = 0;
    pool.status = PoolStatus::Draft;
    pool.bump = pool_bump;
    pool.mint_bump = mint_bump;
    Ok(())
}

use anchor_lang::prelude::*;

use crate::{constants::BPS, error::F2fError};

/// `amount * (1 + yield_bps / 10_000)`, computed in u128 so large pools cannot wrap.
pub fn with_yield(amount: u64, yield_bps: u16) -> Result<u64> {
    let v = (amount as u128)
        .checked_mul(BPS as u128 + yield_bps as u128)
        .ok_or(F2fError::MathOverflow)?
        / BPS as u128;
    u64::try_from(v).map_err(|_| error!(F2fError::MathOverflow))
}

use anchor_spl::token_interface::{transfer_checked, Mint, TokenAccount, TokenInterface, TransferChecked};

use crate::{constants::*, error::F2fError, math::with_yield, state::{Config, Pool, PoolStatus}};

#[derive(Accounts)]
pub struct FundRedemption<'info> {
    #[account(address = config.issuer @ F2fError::Unauthorized)]
    pub issuer: Signer<'info>,
    #[account(seeds = [CONFIG_SEED], bump = config.bump)]
    pub config: Account<'info, Config>,
    #[account(mut, seeds = [POOL_SEED, &pool.pool_id.to_le_bytes()], bump = pool.bump)]
    pub pool: Account<'info, Pool>,
    #[account(address = config.usdc_mint)]
    pub usdc_mint: InterfaceAccount<'info, Mint>,
    #[account(mut, token::mint = usdc_mint, token::authority = issuer, token::token_program = usdc_token_program)]
    pub issuer_usdc: InterfaceAccount<'info, TokenAccount>,
    #[account(mut, address = pool.vault)]
    pub vault: InterfaceAccount<'info, TokenAccount>,
    pub usdc_token_program: Interface<'info, TokenInterface>,
}

pub fn handle_fund_redemption(ctx: Context<FundRedemption>, amount: u64) -> Result<()> {
    require!(ctx.accounts.pool.status == PoolStatus::Funded, F2fError::PoolNotFunded);
    if amount > 0 {
        transfer_checked(
            CpiContext::new(
                ctx.accounts.usdc_token_program.key(),
                TransferChecked {
                    from: ctx.accounts.issuer_usdc.to_account_info(),
                    mint: ctx.accounts.usdc_mint.to_account_info(),
                    to: ctx.accounts.vault.to_account_info(),
                    authority: ctx.accounts.issuer.to_account_info(),
                },
            ),
            amount,
            ctx.accounts.usdc_mint.decimals,
        )?;
        ctx.accounts.vault.reload()?;
    }
    let pool = &mut ctx.accounts.pool;
    let due = with_yield(pool.raised_amount, pool.yield_bps)?;
    let ready = ctx.accounts.vault.amount >= due
        && pool.disbursed_count == pool.project_count
        && pool.settled_count == pool.project_count
        && Clock::get()?.unix_timestamp >= pool.maturity_ts;
    if ready {
        pool.status = PoolStatus::Redeeming;
    }
    Ok(())
}

pub fn handle_redeem(ctx: Context<Redeem>, amount: u64) -> Result<()> {

                authority: ctx.accounts.investor.to_account_info(),

        ),
        amount,
    )?;

    let seeds: &[&[u8]] = &[POOL_SEED, &pool_id_bytes, &[pool.bump]];
    transfer_checked(
        CpiContext::new_with_signer(
            ctx.accounts.usdc_token_program.key(),

                from: ctx.accounts.vault.to_account_info(),
                mint: ctx.accounts.usdc_mint.to_account_info(),
                to: ctx.accounts.investor_usdc.to_account_info(),
                authority: ctx.accounts.pool.to_account_info(),
            },
            &[seeds],
        ),
        payout,
        ctx.accounts.usdc_mint.decimals,
    )?;
    Ok(())
}
